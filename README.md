# InternExcercises-Python

Files are organized by filename prefix where needed:

- `2-*` files are grouped in `session2/`
- `3-*` files are grouped in `session3/`
- `4-*` files are grouped in `session4/`

Files that are already properly named (for example `session9-*`, `session10-*`, `session11-*`, and standalone `.py` files) are intentionally left at the repository root.
